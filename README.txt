WEBSITE PT. AURUM PUSAKA PIJAR

Cara pakai:
1. Buka index.html di browser untuk melihat website.
2. Upload seluruh isi folder ke Netlify/GitHub Pages/hosting biasa.
3. Ganti email dan link WhatsApp di index.html pada bagian kontak.
4. Folder assets berisi 5 materi gambar yang Anda kirim.

Catatan: materi/logo lembaga yang berasal dari gambar pengguna dipakai sebagai visual referensi. Pastikan klaim afiliasi, akreditasi, dan penggunaan logo sesuai izin dan fakta sebenarnya sebelum dipublikasikan.
